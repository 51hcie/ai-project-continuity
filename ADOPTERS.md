# Adoption

This page records real, opt-in use of `ai-project-continuity`. Entries must link to a public repository or other evidence that maintainers can verify. Stars, clones, AI-generated trials, and private claims are not counted as external adoption.

## External adopters

## Add a project

Use the **Adoption report** issue form. Include a public repository URL, the environments or coding agents used, how long the protocol has been in use, and redacted validation evidence. A maintainer will verify the report before adding it here.

Private projects can still provide useful feedback, but they are not listed as publicly verifiable adopters.
