# Session summaries

Copy `_template.md` to `YYYY-MM-DD-short-topic.md`. Use a lowercase, hyphen-separated topic that describes the milestone, not the agent or chat tool.

Create a new summary at a meaningful handoff boundary: a completed milestone, a switch of machine/developer/agent, a context reset, or a blocker that will outlive the current session. Do not create one after every commit or append unrelated milestones to a running file.

Keep published summaries historically stable. If a fact is wrong or unsafe, correct it explicitly or add a later summary that supersedes it. Never copy a full chat transcript or include secrets, personal information, or absolute personal paths.
