# Project collaboration guide

Read `.ai/context.md`, the active decision index and relevant records in `.ai/decisions.md`, and `.ai/tasks.md` before editing. Reviewed reusable prompts are indexed in `.ai/prompts/README.md`. Check `.ai/resources.md` for safe resource locators before asking the user for non-public inputs.

- Keep the first version dependency-free and in-memory.
- Do not add authentication until ADR-002 is resolved.
- Update task evidence after running checks; do not claim unrun commands pass.
- Never put real user or location data in fixtures.
