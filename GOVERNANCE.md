# Governance

`ai-project-continuity` currently uses a maintainer-led model. The primary maintainer sets project direction, reviews changes, manages releases, and handles security reports.

Protocol changes are discussed in public issues before implementation. Decisions prioritize portability, safety, recoverability, and demonstrated use in real repositories. As sustained contributors emerge, maintainership and decision rights may be expanded transparently.

Project decisions, releases, and review history remain public except when coordinated disclosure is required for security or privacy.
