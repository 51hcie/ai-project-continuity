# Roadmap

## v0.1 — foundation

- Define the minimal protocol and recovery invariant.
- Provide a non-destructive initializer, validator, tests, and complete example.
- Establish contribution, security, governance, and release practices.

## Next

- Gather feedback from repositories using the protocol.
- Add fixtures covering more languages and monorepo layouts.
- Define a lightweight conformance report without adding a required runtime.
- Document optional adapters for major coding agents while preserving one neutral source of truth.

Roadmap items are proposals, not promises. Open an issue with a real handoff scenario before proposing new required fields.
